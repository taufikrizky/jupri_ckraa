CERITA KAMI

Memperkenalkan Keindahan Daerah

Explore Sulbar adalah proyek website statis yang dirancang untuk memperkenalkan beragam potensi wisata di Sulawesi Barat melalui tampilan digital yang informatif dan mudah digunakan.

Website ini dikembangkan sebagai bagian dari Ujian Tengah Semester mata kuliah Pemrograman Web Program Studi Pendidikan Teknologi Informasi, Universitas Sulawesi Barat.

Melalui proyek ini, penerapan HTML, CSS, Bootstrap 5, dan JavaScript digunakan untuk membangun website multi-halaman yang responsif.

Jelajahi Wisata
Informasi

Menyajikan pengenalan destinasi wisata daerah.

Mudah Digunakan

Memiliki navigasi yang jelas dan tampilan responsif.

Pembelajaran Web

Menerapkan teknologi web dasar dan framework Bootstrap.
